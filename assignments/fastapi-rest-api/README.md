# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Learn how to build a simple REST API with FastAPI by creating endpoints, handling request data, and returning JSON responses for a small application.

## 📝 Tasks

### 🛠️ Set Up a FastAPI Application

#### Description
Create a basic FastAPI app that serves a welcome message and returns a list of sample items from memory.

#### Requirements
Completed program should:

- Install and import the FastAPI library
- Create a FastAPI app instance
- Add a root endpoint that returns a welcome message
- Add an endpoint to return a list of sample items in JSON format
- Run the app locally with a development server

### 🛠️ Add CRUD Endpoints

#### Description
Extend the API so it can create, read, update, and delete items using REST-style endpoints.

#### Requirements
Completed program should:

- Add a POST endpoint to create a new item
- Add a GET endpoint to fetch all items
- Add a GET endpoint to fetch one item by ID
- Add a PUT endpoint to update an existing item
- Add a DELETE endpoint to remove an item
- Use request models to validate incoming data
- Return appropriate HTTP status codes for successful and invalid requests
