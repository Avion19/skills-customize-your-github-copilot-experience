# 📘 Assignment: To-Do API with FastAPI

## 🎯 Objective

Build a simple to-do list API in Python using FastAPI so you can practice creating routes, handling JSON data, and implementing basic CRUD operations.

## 📝 Tasks

### 🛠️ Create the FastAPI App

#### Description
Set up a basic FastAPI application that serves a welcome message and keeps a list of tasks in memory.

#### Requirements
Completed program should:

- Install and import the FastAPI library
- Create a FastAPI app instance
- Add a root endpoint that returns a welcome message
- Add an endpoint to return the current list of tasks in JSON format
- Run the app locally to confirm the endpoints work

### 🛠️ Add To-Do CRUD Endpoints

#### Description
Extend your API so users can create, view, update, and delete tasks using REST-style endpoints.

#### Requirements
Completed program should:

- Add a POST endpoint to create a new task
- Add a GET endpoint to list all tasks
- Add a GET endpoint to fetch a single task by ID
- Add a PUT endpoint to update an existing task
- Add a DELETE endpoint to remove a task
- Store task data in a Python list or dictionary while the app is running
- Return useful JSON responses and valid HTTP status codes
